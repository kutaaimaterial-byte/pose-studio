## 边界

完整预设库本批均为**静态**。套组播放是有真实时长的切镜预演，不宣称人物表演或运镜动画。原动画库仍在高级模式可用。

提示词是本地预设匹配，不调用模型 API。超出两人、白模/基础舞台、预设动作和构图的要求会警示。明确时间段中的空隙/重叠会提示无法执行，预设序列连续排列。另一方案为保持套组连续性的镜像构图；指定 A/B 左右关系时不擅自镜像。

预设默认追加而非替换。已有项目不作破坏式迁移。横竖切换保留当前人物状态，不静默重排人物路径。

## 验证

- 28 项单元测试：预设完整性、独立画幅、轴侧与身份、8 秒方案、时间解析、能力边界、实际相机构图、镜像、重排、图历史与原有动画/舞台回归。
- 隔离 Chromium：草稿不写时间轴、双人四镜套组、静态空轨、PNG 保存、画幅切换、重排和追加保护、可选高级入口、提示词直达方案。
- 带自然行走动画的原镜头进行构图微调：新副本保留姿态/根轨关键帧、时长与旧确认图，原镜头不变。
- 对 22 张横竖版真实渲染图逐项检查；修正竖版抬手截断和手部取景偏差。缩放监听使用帧调度，避免 ResizeObserver 循环。
- 保持用户已选 Precision Light。Impeccable 单次检测只提示历史 DESIGN 文档与既有浅蓝色/紧凑字号/圆角尺度的差异；不借此回改其他旧界面。预设卡采用必要的实际缩略图，非装饰性卡片。

## 使用入口与保护

项目中点击顶部「姿势」，右侧选择「姿态 / 动态 / 双人互动」。常用按高频任务排序，另外支持收藏、最近使用、用途与文本搜索。卡片封面来自实际骨骼渲染，横竖版分别取景，鼠标悬停显示 12 帧预览；不使用生成图片代替动作。

点击动作仅预览，不修改已保存场景。取消或离开动作工具恢复原场景；双人预览取消后不会保存临时人物。预览内横竖切换不写入旧镜头。点击「当前镜头另存新版本」保留原镜头，追加独立新镜头，时长不短于原镜头或完整动作。「新建动作镜头」使用动作默认时长。

动作烘焙到现有姿态/根移动轨道；双人轨道通过人物 ID 绑定。预览、时间轴、拖动播放头、图片保存共用原有求值器，没有第二套持久播放器。循环移动保留连续根路径，运镜不随人物源动作循环。一次性动作结束后保持末姿，拖短时长有完整过程保护，暂不允许直接切分源动作；可调速或另存版本。

暂停后「保存当前姿态」记录实际骨骼四元数、位移和根姿态，保存到现有姿态收藏；不是只记录基础姿态名称。图片沿用干净 PNG 导出。源镜头、确认图片、其他人物轨道和其他项目保持独立。

## 开放内容

静态：弯腰鞠躬、前倾伸手、仰身躲避、双臂护头、侧向踢腿定格、单腿提膝、俯身避障奔跑、侧身避让奔跑、跪姿双手前伸、跪姿掩面。

动态：自然呼吸、抬头、低头、转头看身后、点头、摇头、举手示意、挥手招呼、伸手指向、双手叉腰、双臂抱胸、摸头挠头、自然行走、慢跑、冲刺跑、坐下、从椅子起身、弯腰鞠躬、走入后停下、奔跑急停、伸手后收回。

互动：对视交谈、拥抱、扶肩行走。当前适配内置同体型白模；不同身高/体型的精确接触重定向尚未支持。

坐下/起身自动加载简易椅子。基础行走、慢跑、冲刺、坐下、起身使用完整授权源骨骼片段，并适配当前人物；走停/跑停在此基础上做连续减速和重心恢复。站立阶段做脚部约束，以减少根路径与脚步不一致的滑动。

## 仍未完成，不计入可用数量

- 78 个静态草稿仍需修正身体协调、地面接触、手势与支撑物匹配。
- 27 个动态草稿仍需制作和逐帧检查；喝水、开关门、拿放物品不能以空手或缺少道具的版本上架。
- 握手、击掌、碰拳、递物已制作协调时序草稿，但手掌/道具接触尚未达到发布标准，未显示为可用卡片。其他 17 组互动仍待制作。
- 左右手、镜像、速度等统一快捷变体还未接入新卡片；既有高级编辑入口继续保留。
- 动作已接入现有镜头/时间轴；自然语言完整动作匹配与节点卡片信息仍沿用旧能力，不宣称支持任意新动作生成。
- 横竖版为当前默认白模生成不同取景。非默认体型、复杂场景遮挡和长时间多次循环的自动全程取景仍需进一步检查。

## 资产与复现

使用 Quaternius 作者在 OpenGameArt 发布的 Universal Animation Library Standard（CC0），不是付费 Pro/Source 版本。来源与许可记录在 `public/assets/motions/LICENSE.txt`。

`scripts/retarget-quaternius.mjs` 将作者 Standard GLB 中 13 个候选片段重定向到现有骨骼。并非 13 个全部成为可用卡片；映射与发布名单见 `app/motion-authoring.ts`。

`scripts/render-action-covers.mjs` 在本地预览服务中从实际人物生成已开放动作的两种画幅、各 12 帧封面。运行时直接加载图片，避免打开面板时重新烘焙整套库。

## 检查说明

- `tests/action-tracks.test.ts`：人物绑定、常量骨骼压缩、循环根连续性、一次性末姿、相机独立时间、复制引用。
- `tests/action-library.e2e.mjs`：隔离预览、取消、保存动态定格、加入镜头、本地保存与刷新恢复。
- `tests/action-interactions.e2e.mjs`：双人预览取消、角色复用、椅子、原镜头/相机/时长保护、跨项目隔离与恢复。
- `scripts/audit-action-library.mjs`：48 份草稿数据的有限性、编译、序列化一致性、脚步约束和已制作互动的实际预览。数据检查通过不代表草稿达到发布质量。
- `scripts/audit-static-expansion.mjs`：无支撑物静态草稿的实际模型检查图。

界面遵循现有 Precision Light；12px 紧凑元信息和高对比警示文字是对既有样式的延续，不据机械检测建议改版整个编辑器。
